# Indian first names and surnames, always masked as [PERSON] (M20, D21).
# spaCy's small English model missed 39% of fake Indian names in titles (first names alone: 72%),
# so this list backs it up, the way indian_places.txt backs up place names.
#
# How it's matched (name_recognizers.py): whole words, only when Capitalized ("Amit") or in
# ALL CAPS ("AMIT"); lower case is left alone, so "ram usage" or "pooja holidays" in lower case
# stay visible. A Capitalized word right before a listed SURNAME is masked too, even if that
# first name isn't listed ("Yashwanth Chowdary"). Initials next to a listed name go with it.
#
# Left out on purpose (spaCy still catches some of them):
#   - names that are also common English words or tech terms: Sunny, Ruby, Jasmine, Rose, Joy,
#     Hope, Prince, Lucky, Ram, Dev, Om, Jay;
#   - names that mostly appear as ordinary Hindi words in titles: Raja, Rani, Amar, Sona, Heera, Moti;
#   - surnames that are brand names: Bose, Tata, Birla, Bajaj, Mahindra, Godrej, Kotak.
# Deity and festival names (Durga, Lakshmi, Krishna, Ganesh) ARE listed: "Durga Puja" gets masked.
# That's accepted, failing closed (D21): an exemption could hide a real person named Durga.
#
# Format: a [first names] and a [surnames] section; names separated by commas; anything after a
# # is a comment. Add the names that matter to you; spelling variants count as separate names.
